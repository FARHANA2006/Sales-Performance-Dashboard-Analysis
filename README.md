Sales performance Dashboard Analysis | Excel
Project Overview
Sales Performance Dashboard is an interactive Excel project that analyzes key metrics such as Sales, Profit, Quantity Sold, and Discounts. Using Pivot Tables, Charts, and Slicers, it provides insights into regional, category, segment, and country-wise performance, supporting data-driven business decisions.

Total Sales
Total Profit
Total Quantity Sold
Average Discount
